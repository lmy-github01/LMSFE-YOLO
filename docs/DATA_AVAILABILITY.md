# Code and data availability

The LMSFE-YOLO source code, model configurations, training/evaluation entry points, dependency specifications, and uploaded CSV result files are available at [the project repository](https://github.com/lmy-github01/LMSFE-YOLO).

Version `v1.0.0` is archived in Zenodo: [10.5281/zenodo.24027516](https://doi.org/10.5281/zenodo.24027516).

Result-file descriptions are provided in [ultralytics/results/README.md](../ultralytics/results/README.md). Dataset sources, experimental subsets, and class mappings are documented in [DATASETS.md](DATASETS.md).

VisDrone2019-DET, original AI-TOD, TinyPerson, and RS-STOD are obtained from their official providers. Third-party images and original annotations remain subject to the corresponding dataset terms. The code is distributed under its GNU AGPL license, and author-generated numerical CSV result files are shared under CC BY 4.0 as stated in their [license file](../ultralytics/results/LICENSE.md).
